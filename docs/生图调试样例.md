# 儿童绘本生图对照样例

每个故事按行逐格输入。两组使用相同原文与画风。“画面核对点”只供评审使用，避免提前向提取模型提供答案。表中均为预期，尚未评分。

| 格 | 输入原文 | 画面核对点 |
|---|---|---|
| A1 | 白兔豆豆有一只灰耳尖，它蹲在桌旁捡起一根蓝蜡笔。 | 白兔、单侧灰耳尖、伸爪捡蓝蜡笔 |
| A2 | 它用刚捡的蜡笔在纸上画了一个圆。 | 豆豆持蓝蜡笔，笔尖贴纸，纸上一个蓝圆 |
| A3 | 豆豆放下蜡笔，双手护住旁边的蜡烛，没有吹灭火苗。 | 蜡笔已放下，双爪护住亮着的火苗 |
| A4 | 它换上绿色背心，举起刚画好的那张纸。 | 同一白兔，绿背心，举纸展示蓝圆 |
| B1 | 戴黄帽的小熊撑着红伞，走到穿蓝衣的小猫身边。 | 小熊持伞，小猫在旁，穿戴归属正确 |
| B2 | 小熊把伞递给小猫，小猫伸爪去接。 | 伞在交接中，给与接的方向正确 |
| B3 | 小猫接过伞，高高举在小熊头顶。 | 小猫持伞，小熊在伞下 |
| B4 | 小熊摘下黄帽子，替小猫戴好。 | 黄帽转到小猫头上，小熊赤头，小猫仍持伞 |
| C1 | 一只尾尖雪白的小狐狸蹲在门边系鞋带。 | 狐狸、白尾尖、蹲姿，爪靠近鞋带 |
| C2 | 屋里，戴圆眼镜的小獾独自把两个苹果放进篮子。 | 仅小獾，圆眼镜，两个苹果，一个篮子 |
| C3 | 门外，小狐狸踮起脚敲了敲门。 | 首格狐狸重现，踮脚敲门，无小獾 |
| C4 | 小獾打开门，把刚装好的篮子递给小狐狸。 | 同一小獾给、同一狐狸接，篮内两个苹果 |

## 评审记录

每格记录组别、模型、提取结果、实际生图提示、图片文件、首次耗时及账面费用。先隐藏原文写下看图复述，再对照上表分别标记动作、角色归属、道具状态和角色外观。遮挡导致不可判读时记录“无法确认”。将同一角色的图片打乱后再做外观判断。将失败格和最难通过格的复测与首次结果分开统计。
