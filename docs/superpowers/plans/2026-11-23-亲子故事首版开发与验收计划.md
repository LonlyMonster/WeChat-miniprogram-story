# 亲子故事四格漫画 · 首版开发与验收计划

首个可联调里程碑是让家长输入五段文字，在第五格仍在生成时保存故事，再用另一台设备登录，读到顺序正确的两页漫画。先用可控的生成任务验证这条流程，再接入真实录音和模型，便于定位顺序、保存和设备兼容问题。

产品规则以 [V1.5 设计稿](../specs/2026-11-23-亲子故事四格漫画-design.md) 为准，页面层级、文案、布局与交互对照 家长端 UI 和 管理端 UI。UI 中的示例登录、录音、图片和管理操作仅供走查。以下里程碑按依赖排序，勾选代表该阶段已有可复核的验收记录。

## 开发里程碑

| 阶段 | 开发交付与依赖 | 阶段出口 |
| --- | --- | --- |
| M1 账号与私人书架 | 建立 HTTPS 家长站、业务后端、安全会话、账号与作品归属、私有媒体读取；完成注册、登录、退出和空书架。确定故事、页内格序、已采用版本、候选版本、任务与存储标识的关联。 | 两个家庭换号及跨设备登录通过 A1。 |
| M2 文字讲述到成书 | 基于 M1，提交文字时分配固定序号并记录任务，四格一页。实现继续讲、讲完、命名、幂等保存、封面回填和持久化重读。用可控任务产生乱序、失败及延迟。 | 演示五格主流程、保存边界和 24 小时草稿规则，见 A2–A4。 |
| M3 录音与真实出图 | 接入单格录音、重新讲、转写纠错、文字回退；接入选择性画面提取、角色特征、输入与图片审核。任务预留额度并锁定模型配置，记录实际调用及费用，支持状态核对和重试。 | 用真实服务完成 A5–A7，记录画质、费用和等待时间。 |
| M4 编辑与作品管理 | 基于已采用版本实现单格放大、修改或重录、候选对照、原子采用；完成书架删除、注销与清理任务。 | 跨设备验证 A8、A9、A10，核对私有存储。 |
| M5 独立管理站 | 账号模块完成后可开发用户管理；与 M3 联调模型配置。接入私网或身份网关、源站访问限制、独立管理员 MFA、权限与操作审计。 | 通过 A11、A12，普通家庭账号无法进入管理功能。 |
| M6 发布验证 | 在候选发布版本执行全量用例、六类真机矩阵和运维演练。 | 按文末发布条件核验并记录结论。 |

## 功能验收单

准备甲乙两个家庭账号、独立管理员、两台可同时登录的设备、可控制时间与任务完成顺序的测试环境。使用五段易区分的正文，按格核对文字、图片、版本和封面。用服务端任务、调用及额度记录交叉核对页面结果。

| 编号 | 操作 | 通过条件 |
| --- | --- | --- |
| A1 家庭隔离 | 仅用用户名密码注册，测试重名、错密、退出换号、浏览器返回，以及乙读取甲的故事、草稿、任务、候选图和媒体。 | 注册自动登录，重名有提示，登录失败统一提示；乙无法读取或修改甲的数据；退出后旧会话失效且无上一账号的预览。 |
| A2 顺序与重读 | 连交五格，令第二格先完成；首格和第五格未完成时结束、命名并保存，随后退出。后台完成后在另一台设备重读。 | 生成中仍可录入。书架先显示“封面生成中”，随后取首格，显示正确名称、日期；第一页按左右、上下排四格，第二页一格；每格可放大并读到对应正文。重读新增模型调用为零。 |
| A3 入架条件 | 分别在讲述中退出、仅结束单格、退出保存页、提交纯空格名称，再对有效保存模拟断网重试及双击。 | 前四种均无新增作品；空名提示“请填写故事名称”。服务端仅接受已结束且名称有效的作品，有效重试只入架一次，显示“已加入书架”。 |
| A4 草稿期限 | 从服务端首次接受第一格生成请求计时，在第 23 小时跨设备继续讲、编辑或重试；在第 24 小时检查，模拟保存与清理同时发生、任务迟到。 | 到期前恢复文字与已生成漫画；操作不续期。到期未入架草稿清除，迟到结果不能写回。并发处理只产生一个有效结局，已入架作品可重读。 |
| A5 语音 | 授权前查看用途、处理方与保留时间；录音中停顿、重新讲，再点“这格讲完了”；模拟拒绝授权、设备不支持、来电中断及错误转写。 | 停顿不提交；重讲丢弃前次采集，只有最终提交进入队列，结束释放麦克风。可恢复录入或改用文字、修正正文。转写或放弃后清除临时音频，中断残留按短时策略清理。 |
| A6 情节与适龄 | 分别输入单动作短句、多动作口述及设计稿“没摘花、给花浇水”样例；测试首次生成、重画的审核拒绝与审核中断。 | 短句走直接描述，复杂口述按需提取；保留否定、顺序、角色设定和正文。提取失败回退到经检查的正文。原输入与提取结果均筛查，图片通过检查才可作预览、缩略图或封面。失败留文，可修改或重试。 |
| A7 额度与画质 | 双击生成、断网重试、模拟供应商结果未知、并发及预算触顶。用相同样本、模型、尺寸和画风对照直接出图与选择性提取。 | 同一请求只建一项任务，结果未知先核对，额度与调用可对账；达到上限暂停新生成，仍可重读。记录首图可见耗时中位数及 P95、角色一致性、情节画对率、每格采用前总费用。用连续两格观察儿童能否认出同一角色、指出动作并照画主体，保留观察结论。 |
| A8 单格版本 | 重画第二格，在另一设备读原版；依次测试放弃、失败、采用，再重画首格；模拟两端同时采用和旧任务迟到。 | 放弃或失败保留原图文；采用一次替换对应图文，其他格不变；首格采用时同步换封面。冲突提示刷新，迟到任务不能覆盖已采用版本。 |
| A9 书架阅读 | 用五格测试故事跨页阅读，点开第一格并滑动到最后一格。 | 标题、格序、正文和图片与书架作品一致；预览中无图片导出或保存到相册入口。 |
| A10 删除与注销 | 对指定作品打开删除弹窗，先取消再确认；重发删除、读取旧图、投递迟到结果，模拟清除失败；另用测试账号注销。 | 弹窗显示故事名与影响，默认焦点在取消。确认后立即撤销相应访问，作品不能复现；正文、图片与候选图启动清除，失败持续重试。核对受管备份、快照及对象历史未包含作品内容。 |
| A11 用户管理 | 核对全部注册用户及“用户名、最近登录时间、操作”三列。在指定行取消或确认重置，分别测试临时密码过期、复用及首次登录。 | 取消无变更；确认后只撤销目标账号旧密码和会话。管理员看到逐次随机生成的短效一次性密码，用户首次登录强制改密；审计可查操作者、目标和时间。 |
| A12 模型配置 | 检查初始值，提交服务商与模型不匹配、缺少密钥、无效额度，再保存有效配置并重开页面。切换前后各提交任务，包含重画。 | 默认百炼 wanx2.0-t2i-turbo；展示全站月预算、每账号额度和密钥状态。无效值提示原因且保留原值；有效变更留审计，在途任务沿用原模型与计费记录，新任务使用新值。模型不可用时提示管理员，切换高价模型由管理员选择。 |

## 真机、运维与发布判定

- [ ] 按发布日滚动 36 个月列出稳定系统、浏览器、微信版本的可安装组合。设计基准窗口为 2023-11-23 至 2026-11-23。分别覆盖 iPhone、iPad、安卓手机、安卓平板、鸿蒙手机、鸿蒙平板，每类覆盖系统主流浏览器和微信聊天内打开网址。记录型号、系统、客户端版本、实际内核及用例结果；无法安装和未测组合分别标明。
- [ ] 每类入口实测注册登录、授权与拒绝、录音格式、来电恢复、重新讲、文字录入、重画、保存、分页重读及单格查看。对照 UI 截图核验手机竖屏、平板横竖屏均优先展示四格；旋转后当前页与录音控件仍可用；软键盘弹起后能命名并保存。
- [ ] 核查独立盐 Argon2id、账号及请求来源限速、安全 Cookie、登录时更新会话、空闲及绝对有效期、写操作跨站请求令牌、私人页面与媒体 no-store。验证音频真实格式、字节与解码时长限制及隔离处理，含标记标题按纯文本显示，数据查询参数化。
- [ ] 核实数据库与图片加密、供应商地域与留存及训练设置；仅向供应商发送本格必要数据。抽查前端资源、响应及日志无密钥或意外披露的家庭内容；日志仅留任务编号、耗时、错误类型、用量等必要字段。演练密钥轮换与吊销、服务重建、删除重试、异常登录、费用及积压告警。
- [ ] 接真实服务前落实个人账号模型资格、处理地域、临时数据清理期限、预算与并发值；对照设计稿的月 144 张样例，分别记录图像、语音、提取、审核、存储及主机费用。界面示例数值和设计稿估算均需与试用环境实值分列。
- [ ] 发布记录逐项附版本、执行环境、预期、实测及证据。功能项附截图；并发、清理与费用项附脱敏任务记录及账目。家庭主流程、访问隔离、适龄审核、删除或计费一致性失败时阻断发布；修复后重测失败项及相邻流程。真机必测入口缺证据时保持待验，不标记兼容通过。

当前交付为计划。阶段排序与验收记录格式为实施建议；排期取决于人员、真机和供应商账号到位情况。模型效果、实际价格与兼容结论由联调及真机记录确定。
